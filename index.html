What is WindPipeDB?

WindPipeDB is Windipi's database product — the first of what we build. It's designed to be practical, adaptable, and ready to fit into the way you already work.

Key characteristics

  • Built and maintained by Windipi.
  • Flexible enough to grow with your project.
  • Straightforward to set up and use.
  • Direct support from the team who made it.

Note: WindPipeDB is still in development. It is not yet available to download, install, or use.

Availability

WindPipeDB isn't released yet. You cannot create a database, install it, or use it at this time — it's still being built.

When it's ready, this page will be the first place updated with details on how to get started.

Not available yet. There's no download, no install, and no sign-up. Check back later for the first release.

WindPipeDB API

The WindPipeDB API lets you interact with databases programmatically — creating them, reading and writing records, and managing access.

It's currently available to Windipi testers for testing and early usage. Public access is not available yet.

WindPipeDB API

Testers only Some features may not work

The API is live and available to Windipi testers. Access is by invitation only — there's no public sign-up, and the API is not publicly reachable. Because it's still evolving, some features may not work as expected.
